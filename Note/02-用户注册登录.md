# 用户注册与登录

## 一、功能说明

实现用户的注册与登录，并对笔记操作加权限控制：
- 新增笔记时记录发布者
- 只能修改/删除自己的笔记

## 二、表结构

### users 表
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(100) NOT NULL COMMENT '密码',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间'
);
```

notes 表新增 user_id 字段

```sql
ALTER TABLE notes ADD COLUMN user_id INT COMMENT '发布者ID';
```

设计说明： 用 user_id（数字）而不是用户名做外键，因为用户名可能被改，ID 唯一且不变。

## 三、接口设计

POST /api/users/register 用户注册

POST /api/users/login 用户登录
笔记接口通过请求头 userId 传递当前用户身份。

## 四、核心代码

UserMapper.java

```java
@Mapper
public interface UserMapper {
    @Insert("INSERT INTO users(username, password) VALUES(#{username}, #{password})")
    @Options(useGeneratedKeys = true, keyProperty = "id")
    void insert(User user);

    @Select("SELECT * FROM users WHERE username = #{username}")
    User findByUsername(String username);
}
```

UserController.java

```java
@RestController
@RequestMapping("/api/users")
public class UserController {

    @Autowired
    private UserMapper userMapper;

    @PostMapping("/register")
    public User register(@RequestBody User user) {
        userMapper.insert(user);
        user.setPassword(null);  // 返回时不带密码
        return user;
    }

    @PostMapping("/login")
    public User login(@RequestBody User user) {
        User found = userMapper.findByUsername(user.getUsername());
        if (found == null || !found.getPassword().equals(user.getPassword())) {
            throw new RuntimeException("用户名或密码错误");
        }
        found.setPassword(null);
        return found;
    }
}
```

权限控制（NoteController 里）

```java
@PutMapping("/{id}")
public String update(@PathVariable Integer id, @RequestBody Note note,
                     @RequestHeader(value = "userId", required = false) Integer userId) {
    Note existing = noteMapper.findById(id);
    if (existing == null) {
        return "笔记不存在";
    }
    if (userId == null || !userId.equals(existing.getUserId())) {
        return "无权修改别人的笔记";
    }
    note.setId(id);
    noteMapper.update(note);
    return "修改成功";
}
```

代码说明：

· 先从数据库查出笔记，看它的 user_id 是谁
· 再对比请求头里的 userId
· 一致 → 允许操作；不一致 → 返回“无权”
