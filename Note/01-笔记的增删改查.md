# 笔记增删改查

## 一、功能说明

实现对笔记的基本操作：新增、查询、修改、删除。
数据存储在 MySQL 的 `notes` 表中。

## 二、表结构

```sql
CREATE TABLE notes (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '笔记ID',
    content TEXT NOT NULL COMMENT '笔记正文',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '发布时间'
);
```

## 三、接口设计

POST /api/notes 新增笔记

GET /api/notes/{id} 按 ID 查询笔记

PUT /api/notes/{id} 修改笔记

DELETE /api/notes/{id} 删除笔记

GET /api/notes 查询所有笔记

## 四、核心代码

- NoteMapper.java（MyBatis 数据访问）

```java
@Mapper
public interface NoteMapper {
    @Insert("INSERT INTO notes(content, created_at) VALUES(#{content}, #{createdAt})")
    @Options(useGeneratedKeys = true, keyProperty = "id")
    void insert(Note note);

    @Select("SELECT * FROM notes WHERE id = #{id}")
    Note findById(Integer id);

    @Update("UPDATE notes SET content = #{content} WHERE id = #{id}")
    void update(Note note);

    @Delete("DELETE FROM notes WHERE id = #{id}")
    void deleteById(Integer id);
}
```

代码说明：

· @Insert / @Select / @Update / @Delete 对应 SQL 的四种操作
· #{content} 是占位符，MyBatis 会自动替换成 note.getContent()
· @Options(useGeneratedKeys = true, keyProperty = "id") 让插入后自动把数据库生成的 id 回填到对象上

- NoteController.java（接口）

```java
@RestController
@RequestMapping("/api/notes")
public class NoteController {

    @Autowired
    private NoteMapper noteMapper;

    @PostMapping
    public Note create(@RequestBody Note note) {
        note.setCreatedAt(LocalDateTime.now());
        noteMapper.insert(note);
        return note;
    }

    @GetMapping("/{id}")
    public Note get(@PathVariable Integer id) {
        return noteMapper.findById(id);
    }

    @PutMapping("/{id}")
    public Note update(@PathVariable Integer id, @RequestBody Note note) {
        note.setId(id);
        noteMapper.update(note);
        return noteMapper.findById(id);
    }

    @DeleteMapping("/{id}")
    public String delete(@PathVariable Integer id) {
        noteMapper.deleteById(id);
        return "deleted";
    }
}
```

代码说明：

· @RestController 把返回值自动转成 JSON
· @RequestMapping("/api/notes") 定义基础路径
· @RequestBody 把请求体里的 JSON 转成 Java 对象
· @PathVariable 取出 URL 里的 {id}
